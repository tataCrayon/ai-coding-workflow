# Workflow E：资产校验与自动更新 (Validate & Auto-Update)

> **触发词**："校验资产"、"更新资产"、"资产适配"、"代码变动后同步资产"

与巡检（Workflow C）的核心区别：**巡检是"发现问题 → 报告 → 等用户确认"，校验更新是"发现问题 → 自动修复 → 汇报结果"**。子代理拥有编辑权限。

## E.0 校验范围与策略确认

触发后**自动确定**校验范围（无需询问用户）：

**修复策略分级**（子代理内部自动执行）：

| 问题类型 | 修复策略 | 示例 |
|---------|---------|------|
| 🟢 **事实性错误** | 直接修复 | 类名/方法名变更、文件路径变更、签名变化 |
| 🟡 **格式缺失** | 直接补充 | 缺少 AI 检索关键词、缺少 Graph Links 章节 |
| 🔴 **业务逻辑变更** | 仅报告，不修改 | 核心逻辑描述与代码不一致 |
| ⚫ **资产引用的类/方法已删除** | 标记为 `[已删除]` 并报告 | 类被整体删除、方法被移除 |

## E.1 创建校验任务

在 `.agent/context/` 下创建校验任务实例文件。

## E.2 分批派发校验子代理（Map 阶段）

采用与巡检相同的 **Map-Reduce** 架构，但子代理拥有**编辑权限**。

**子代理校验修复任务 Prompt 模板**：

```
【任务类型】编辑任务

【任务目标】
对 `.notes/{target_dir}/` 目录下的所有资产文件执行代码一致性校验，并自动修复事实性错误。

【必须做】
1. 使用 列举文件 列出 `.notes/{target_dir}/` 下的所有 .md 文件
2. 逐个使用 读取文件 读取每个资产文件的完整内容
3. 对每个文件执行以下校验：

   ① 代码引用校验（核心）：
   - 提取"关联代码入口"表格中的所有代码引用
   - 使用 文件搜索 验证对应的源文件是否存在
   - 如果存在但路径/名称变更 → 使用 file_replace 更新资产中的引用
   - 如果已被删除且无替代 → 在表格中标注 `[已删除]`，记录到报告

   ② 格式完整性补充：
   - 缺少"AI 检索关键词" → 自动生成并补充
   - 缺少"知识图谱关联 (Graph Links)"章节 → 添加空模板章节
   - 缺少"关联代码入口"表格 → 添加空模板表格

   ③ Graph Links 死链修复：
   - 检查相对路径链接，验证目标文件是否存在
   - 已移动 → 更新链接路径
   - 已删除 → 移除该链接并记录

   ④ 业务逻辑一致性检查（仅报告，不修改）：
   - 核心业务规则描述与代码明显不一致 → 记录到"需人工确认"部分

4. 修复完成后，更新资产文件头部的"更新时间"字段

【禁止行为】
- 不要修改资产中的业务逻辑描述
- 不要删除或创建资产文件
- 不要修改目标目录以外的文件（除非修复 Graph Links 反向链接）
- 不要修改代码文件

【返回格式】
---
## 校验修复报告：{target_dir}
- 校验文件数：{N}
- 自动修复数：{N}
- 需人工确认数：{N}
- 无变化文件数：{N}

### ✅ 自动修复项
| # | 资产文件 | 修复类型 | 修复前 | 修复后 | 说明 |
|---|---------|---------|--------|--------|------|

### ⚠️ 需人工确认
| # | 资产文件 | 问题类型 | 问题描述 | 建议处理方式 |
|---|---------|---------|---------|------------|

### ⚫ 已删除标记
| # | 资产文件 | 被删除的引用 | 说明 |
|---|---------|------------|------|

### 文件清单
| 文件名 | 代码引用 | 格式 | 图谱链接 | 业务逻辑 | 状态 |
|--------|---------|------|---------|---------|------|
---
```

## E.3 汇总校验报告（Reduce 阶段）

Orchestrator 收集所有子代理返回的修复报告后：

1. **合并修复项**
2. **索引一致性同步**：检查 `knowledge-index.md` 是否需要同步更新
3. **更新校验任务实例文件**
4. **输出校验摘要**：

```markdown
## 📋 资产校验完成
- **校验时间**：YYYY-MM-DD
- **校验范围**：[全量 / 指定范围]
- **校验文件数**：{N}
- **自动修复**：{N} 项
- **需人工确认**：{N} 项
- **已删除标记**：{N} 项
- **无变化**：{N} 个文件

### 需人工确认的项（如有）
| # | 资产文件 | 问题描述 |
|---|---------|---------|

> 完整报告已保存至：`.agent/context/{YYYYMMDD}_资产校验_{scope}.md`
```
