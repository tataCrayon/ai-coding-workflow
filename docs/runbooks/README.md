# 可执行手册（runbooks）

> verified: 2026-11-23 ｜ 验证方式: 目录约定实测

## 什么进 runbooks

**有顺序、有回滚、能照抄执行**的操作。判据：

| 特征 | 进 runbooks | 不进 |
|---|---|---|
| 有明确步骤顺序 | ✅ | 概念解释 → `docs/domains/` |
| 出错要回滚 | ✅ | 一次性调研 → `.specs/` |
| 需要贴命令/SQL | ✅ | 决策权衡 → `docs/architecture/decisions/` |

## 文件格式

```markdown
# <动作短语>（例如：回滚某服务发布）

> verified: 2026-11-19 ｜ 验证方式: SIT 实跑一次
>
> 适用：<什么情况下用这份>
> 预计耗时：<X 分钟> ｜ 可回滚：是/否

## 前置检查

- [ ] 检查项 1（命令）
- [ ] 检查项 2（命令）

## 步骤

### 1. <步骤名>

```bash
<可直接复制的命令>
```

预期输出：<长什么样>

### 2. <步骤名>
...

## 回滚

<反向操作，逐步可执行>

## 已知坑

| 现象 | 原因 | 处理 |
|---|---|---|
| <报错原文> | <根因> | <动作> |
```

## 命名

`runbooks/{动词短语}.md` 或 `.sql`，动词开头：`rollback-`、`migrate-`、`verify-`、`rotate-`。

## 过期纪律

runbooks 阈值 **30 天**（[ADR-0003](../architecture/decisions/ADR-0003-doc-freshness.md)）。
超过 30 天未核对的，执行前**必须先重新验证**，或先把 `verified` 更新到位。
